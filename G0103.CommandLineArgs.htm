Understanding Command-Line Arguments in Python

Command-line arguments are a powerful feature that allows users to provide input to a program at runtime. Understanding how to use command-line arguments can significantly enhance the flexibility and usability of your scripts. This lesson will cover

  • the basics of command-line arguments,
  • how to enter and access them in Python, and
  • some practical examples to illustrate their use.

What Are Command-Line Arguments?

Command-line arguments are parameters passed to a program when it is executed from the command line. They allow users to specify options or parameters that can influence the behavior of the program without changing the code. For example, a script that processes files might take the file name as a command-line argument.

Accessing Command-Line Arguments in Python

In Python, command-line arguments are stored in a list called sys.argv, which is part of the sys module. The first element of this list, sys.argv[0], is the name of the script itself. The subsequent elements are the arguments passed to the script. 

Here is a simple example to illustrate this:

import sys

# Print the name of the script
print("Script name:", sys.argv[0])

# Print the command-line arguments
for i, arg in enumerate(sys.argv[1:], start=1):
    print(f"Argument {i}: {arg}")

Create this script using your favorite text editor, save it in a file named script.py, and run it from the command line.

For example, to run this script from the command line, you would enter the following command:

python script.py arg1 arg2 arg3

The output would be:

Script name: script.py
Argument 1: arg1
Argument 2: arg2
Argument 3: arg3

In case you don't know how to access the command line, see an explanation in an earlier lesson or ask your favorite AI tool to show you how.

Practical Examples

File Processing Script

Suppose you have a script that processes a file. You can pass the file name as a command-line argument. Here is an example:

import sys

if len(sys.argv) != 2:
    print("Usage: python script.py --filename--")
    sys.exit(1)

filename = sys.argv[1]

with open(filename, 'r') as file:
    content = file.read()
    print(content)

This script checks if exactly one argument (the file name) is provided. If not, it prints a usage message and exits. Otherwise, it reads and prints the content of the specified file.

Create this script using your favorite text editor, save it in a file named script.py, and run it from the command line with the following command where myFile.txt is the name of the file of interest.

python script.py myFile.txt

Calculator Script

You can create a simple calculator that takes two numbers and an operator as command-line arguments:

import sys

if len(sys.argv) != 4:
    print("Usage: python calculator.py --num1-- --operator-- --num2--")
    sys.exit(1)

num1 = float(sys.argv[1])
operator = sys.argv[2]
num2 = float(sys.argv[3])

if operator == '+':
    result = num1 + num2
elif operator == '-':
    result = num1 - num2
elif operator == '*':
    result = num1 * num2
elif operator == '/':
    result = num1 / num2
else:
    print("Invalid operator. Use +, -, *, or /.")
    sys.exit(1)

print(f"Result: {result}")

This script performs basic arithmetic operations based on the provided arguments.

Advanced Command-Line Argument Parsing

For more complex command-line argument parsing, Python provides the argparse module. This module allows you to define expected arguments, their types, default values, and help messages. Here is an example:

import argparse

parser = argparse.ArgumentParser(description="A simple calculator.")
parser.add_argument("num1", type=float, help="First number")
parser.add_argument("operator", choices=['+', '-', '*', '/'], help="Operator")
parser.add_argument("num2", type=float, help="Second number")

args = parser.parse_args()

if args.operator == '+':
    result = args.num1 + args.num2
elif args.operator == '-':
    result = args.num1 - args.num2
elif args.operator == '*':
    result = args.num1 * args.num2
elif args.operator == '/':
    result = args.num1 / args.num2

print(f"Result: {result}")

This script uses argparse to handle command-line arguments more robustly and provides helpful error messages and usage instructions.

Conclusion

Understanding command-line arguments is a fundamental skill for any Python programmer. They allow you to create flexible and user-friendly scripts that can be easily customized by users. By mastering the basics of sys.argv and exploring the argparse module, you can enhance the functionality and usability of your Python programs.
