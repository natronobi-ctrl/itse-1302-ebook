Welcome

Welcome to the courseware for ITSE-1302 Computer Programming: Scientific Python at Austin Community College in Austin, TX.

Course description

Official description

As of April 2023, the catalog description for this course reads as follows:

This course is an introduction to (scientific) computer programming using including design, development, testing, implementation, and documentation. It may include: Python Fundamentals, functions, data structures, classes, objects, statistical programming, data visualization with MatPlotLib and Programming with the NumPy library.

Note that the word (scientific) was inadvertently omitted from the catalog description.

Prerequisite(s): COSC 1336 or Departmental Approval

Note, this is not a programming course for beginners. If your knowledge of Python programming is not at or above a level consistent with the successful completion of COSC 1336, you may have difficulty succeeding in this course.

Practical description

This course and the follow-on course (ITSE-1372 Intermediate Computer Programming Python) are  designed to take you to the next level in Python programming by helping you learn how to use the various components of the Python scientific computing ecosystem, which is described in the Scipy Lecture Notes.

The purpose of this course and the follow-on course is to teach you how to work as a programmer in the technology area known generally as data science and analytics.

Course structure

Communication with your instructor

This is an asynchronous online course. There are no scheduled class meetings and all office hours are online. Communication with your instructor is via email, video conference, or phone, and the Blackboard Learning Management System.

A free eBook

Assignments and tests are keyed to the free eBook, which you are now reading. There should be no requirement for you to access resources outside the eBook. However, sometimes outside resources such as Scipy Lecture Notes can be useful in helping you to better understand the material in the eBook. Feel free to consult such resources if you find that helpful. Also feel free to consult ChatGPT to help you understand the material in the eBook as well as the requirements for the assignments. (As you will see later, a major portion of this eBook is based on information provided by ChatGPT.)

You should start reading the eBook on the first day of class and read a few lessons every day as you progress though the course. If you need to find a discussion of a particular topic, you should open the folder containing the contents of the eBook and use the search capability of your operating system to search for the topic by keyword. Then open the files containing the keyword in your browser and use the search capability of the browser to find the keyword in those files.

Three major units

The course is structured into three units. Assessments such as assignments. quizzes, and tests are administered through Blackboard. The three units included in this course are:

  • Statistical programming in Python
  • Data visualization using Matplotlib
  • Programming with the NumPy library

The Jupyter Notebook

The Jupyter Notebook is an open-source web application that allows you to create and share documents that contain live code, equations, visualizations and narrative text.

You won't be expected to install and use a Jupyter Notebook for any of your programming efforts in this course. However, many of the resources are presented in the format of a Jupyter Notebook. Therefore, it might be helpful for you to know what it is and how to interpret what you are seeing when you view those resources. A quick (approximately 19 minutes) tour of the following three videos should provide that knowledge.

  • The Jupyter Notebook Environment part 1
  • The Jupyter Notebook Environment part 2
  • The Jupyter Notebook Environment part 3

Installing and running Scientific Python

See Installing packages for information on getting the Python scientific computing ecosystem up and running on your computer.

In order to run the sample code provided in this study guide, you will need to either build your own homebrew system, or download and install a Python distribution that supports the Python scientific computing ecosystem such as  Anaconda or WinPython. To get up and running quickly, you can download and install one of the distributions listed under Installing packages. However, there are also some advantages to building your own homebrew system. Even if you decide not to build your own Python scientific development environment, you may find the material in that lesson educational.

Documentation

As is the case with most modern library-oriented programming languages, you will probably need to make frequent reference to the library documentation. Matplotlib documentation is located here. Numpy and Scipy documentation are located here. You can search the Matplotlib documentation here.

Supplemental resources and accessibility notice

Although this eBook is designed to serve as the only required resource for this course, you may find it helpful to explore additional materials that expand on the topics introduced here. Throughout the eBook, you will encounter optional links to external websites, tutorials, and examples that can deepen your understanding of data science and related concepts.

These external materials are offered strictly for optional enrichment. All required learning objectives for this course can be met using only the accessible materials provided within this eBook. You are not expected to visit any external site in order to complete assignments or demonstrate mastery of the course content.

Because these supplemental resources are hosted by third parties, their availability may change without notice, and they have not been evaluated for accessibility compliance. If you choose to explore them, please be aware that they may not meet current accessibility standards.
