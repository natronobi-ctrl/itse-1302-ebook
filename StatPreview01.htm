Introduction

In order to enjoy a successful career in data science programming, you will probably need some knowledge of statistics. This course provides an introduction to descriptive statistics and will get you started down that path.

Prerequisite Knowledge

No prerequisite knowledge of statistics is required in this course, nor should there be any need to study resources beyond this eBook. This eBook is designed to provide everything you will need to know about statistics to succeed in the statistics portion of this course. The prerequisite math requirements are elementary: addition, subtraction, multiplication, and division. The Python programming prerequisite is COSC 1336 Programming Fundamentals I.

Descriptive Statistics

According to ChatGPT, the purpose of descriptive statistics is to summarize and describe the main features and characteristics of a dataset, providing insights into its central tendency, variability, and distribution or shape. Descriptive statistics help to distill the key information in a dataset into a few summary measures, allowing us to better understand and interpret the data.

eBook Organization

As mentioned earlier, this eBook is designed to provide everything that you need to know about statistics to be successful in this course. The statistics portion of the eBook is divided into three main sections, which are intended to be studied in parallel:

  • Theory
  • Practice
  • Review

Each of the lessons in the Theory section discusses an important topic and then points you to one or more lessons in the Practice section for further study. Lessons in the Practice section contain further discussion plus sample Python code and explanatory images.

The topics in the Theory section occur in approximately the same order that those topics appear in homework assignments.

The first lesson in the Practice section contains an index of the topics in each of the Practice lessons.

The Review lesson is designed to help you prepare for the tests.
